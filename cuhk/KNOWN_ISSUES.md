# 已知问题

## 3D 切换后地图卡屏

- **状态：** `unfixed / deferred`
- **影响版本：** V2
- **当前版本缓解措施：** V3 已隐藏 3D 控件，启动流程不再注册 3D 切换，也不会通过正常界面调用 `map.setTerrain`。

### 现象

从 2D 切换到 3D 后，地图渲染可能直接卡住。此时即使再次点击切回 2D，地图也不能恢复，只能刷新页面。

### V2 复现步骤

1. 打开已生成完整 terrain-RGB 数据的 V2 地图。
2. 点击顶部“3D 視角”。
3. 等待地图倾斜并启用 terrain。
4. 观察地图是否停止更新或交互无响应。
5. 再点击“2D 視角”；受影响时卡屏仍然存在。

### 处理决定

V3 只提供稳定的 2D 地图。地形生成模块和不可见的 3D 建筑层暂时保留，方便未来单独排查，但本次不声称问题已经修复。
